**Customer Churn & Retention Analysis**

**Project Overview**

This project analyzes customer churn and retention using the Telco Customer Churn dataset. The dashboard was developed using Microsoft Power BI to identify patterns in customer behavior and understand factors associated with customer churn.

The goal is to generate useful business insights that can help organizations improve customer retention.

**Objectives**

- Analyze customer churn and retention.
- Calculate key performance indicators (KPIs).
- Explore churn patterns across different customer services.
- Identify customer segments with higher churn rates.
- Recommend strategies to improve customer retention.

**Tools & Technologies**

- Microsoft Power BI
- DAX
- Data visualization
- Telco Customer Churn dataset

**Dataset**

The project uses the Telco Customer Churn dataset, which contains information about 7,043 customers, including their services, account details, and churn status.

**Key Performance Indicators**

The dashboard examines the following metrics:

- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate
- Retention Rate

**Analysis**

The analysis explores customer churn patterns in relation to:

- Internet Service
- Tech Support
- Online Security

These comparisons help identify customer groups with different churn patterns.

**Key Findings**

The dataset contains 7,043 customers. The churn and retention KPIs help summarize the overall customer base and highlight the scale of customer attrition.

Further insights can be drawn from the dashboard by comparing churn across service categories and customer segments.

**Business Recommendations**

- Investigate the needs of customer groups with higher churn rates.
- Evaluate whether additional technical support could improve customer satisfaction.
- Review the value and adoption of online security services.
- Monitor churn and retention KPIs regularly.
- Use customer feedback to develop targeted retention strategies.

These recommendations should be evaluated using additional customer and business data before implementation.

**Conclusion**

This project demonstrates how Power BI can be used to analyze customer churn, visualize customer behavior, and support data-driven business decisions.
